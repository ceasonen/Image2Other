# Image2Other

把图片变成方便继续修改的文件。独立项目主页：<https://ceasonen.github.io/Image2Other/>。

主线是 **图片 → 可编辑 SVG 图形与文字 → 修改 → 导出**。OCR 只辅助文字层，不替代图形重建、组件组合与连接关系恢复。

## 四种模式

- **Text + vectors，默认的文字优先重建**：先用本地 OCR 识字，展示原图文字裁切、置信度和可纠正的识别结果；核对后点 Build with reviewed text。选中的字形从描摹中移除，再放入真正的 SVG 文字及 PPT 文本框，图形仍描摹为路径。支持英文及中英混排，无需 API Key；首次需同意下载几 MB 的 OCR 引擎和语言数据，图片不上传。

- **Vector trace，本地描摹**：PNG/JPG 等图片转成真实的彩色矢量路径，支持 SVG 和原生 PPTX 导出。无需 API Key，也不上传图片。图片里的字会变成轮廓，不会自动变成可改字的文本框。
- **AI rebuild，语义重建**：使用你自己的视觉模型，把图重建成可编辑文字、矩形、椭圆、线条、箭头和路径。也可复制提示词到自己的 AI 对话，随后导入 JSON。需要核对识别内容，不能保证原图完全还原。
- **Image formats，格式转换**：PNG/JPEG/WebP 互转，可设置输出大小、压缩质量和 JPEG 背景色。保留像素内容，不进行结构识别。

支持上传、拖拽和剪贴板粘贴。转换后可以在 Layers 中改颜色、透明度、文字和基础坐标，也可以添加文本、删除图层、撤销，以及保存 Scene JSON 继续编辑。

描摹得到的真实矢量路径也可用 X/Y 移动，曲线控制点和孔洞轮廓一起更新；路径范围通过贝塞尔曲线极值计算。Shift 点选或打开 Select multiple，可以让选中的图形和文字一起移动、保持相对位置。这是手动多选，不是自动语义组合。

原生 line 图层新增 Start/End target 与 port：手动选择目标图形和包围框连接点，移动目标后对应端点跟随。直接移动已绑定的线前需先设为 Free。Scene JSON 保留稳定 ID 和约束，SVG 导出附着元数据及更新后的坐标；PPTX 是坐标同步的原生线，**不是 PowerPoint 内的动态连接绑定**。描摹出来的箭头仍是 path，不会自动变成 line；自动关系恢复尚未实现。

图形工作区的 SVG 与原生 PPTX 文字默认 **Times New Roman**。文字图层中也可改为 Arial、Calibri 或 Georgia，Scene JSON 保留字体选择。未嵌入字体，其他设备可能使用替代字体；这不是恢复原图字体。网页按钮等界面字体不变。

生成 SVG 后，现在会在同一工作尺寸下重新渲染，和原图计算 RGB 平均误差并显示差异图。选择一个或多个图层后，点 **Refine selected layers** 会按 4、2、1 像素的顺序尝试局部移动；每轮只保留误差下降的候选，原来的 SVG 图层仍可编辑。手动修改后可以点 **Compare again** 开始新的一轮比较。它只修正小幅位置误差，不判断文字内容、箭头方向或连接关系；更低的像素误差不能证明科研图的语义正确。

**Export experiment ZIP** 由用户手动触发，本地保存工作分辨率原图、渲染图、差异图、初始/最终 Scene JSON 和每次尝试的记录，上限 12 MB。记录标注为 `unverified`，文字、连接、编辑行为及素材使用权仍需单独核对；这些输出不能直接作为经过验证的训练集或独立测试集。网页不会自动收集或上传图片。

新增可选的 **本机 PaddleOCR Python 服务**与 **PaddleOCR JSON 导入**，继续复用同一套文字核对、保护图形、描摹与 SVG 导出流程，不转向单独的 OCR 产品。服务只绑定回环地址，需要会话令牌和明确授权；需已有依赖和本地模型，不自动安装或下载。识别结果默认不选中，旋转文字及预处理后的坐标暂不接受。[配置与验证边界](paddleocr.md)。目前已验证接口/UI，**没有运行真实 Paddle 模型或证明准确率提升**；Re-read label 仍使用浏览器 Tesseract。

## 本地启动

安装 Node.js 24 或更新版本，在项目文件夹运行：

```sh
npm install --ignore-scripts
npm run dev
```

打开 <http://127.0.0.1:5178/Image2Other/>。验证和构建用 `npm test`、`npm run build`。

## 可编辑到底是什么意思

SVG 内是路径/文字/形状，不是套壳 PNG；PPTX 内是原生文本框、形状和曲线。Text + vectors 将已核对文字变成清晰可编辑文字；Vector trace 仍只描摹轮廓。内置样例仅演示编辑和导出，不代表自动识别精度。

OCR 最多放大 2 倍，最长边 2,400、总计 4 百万像素；图形描摹最长边仍为 768。低置信度字不默认替换，复杂背景不擦除；检测到横向或纵向笔画穿过文字框时也暂缓替换，并显示原因。这不是完整的连线识别：斜线、框内短线仍可能被擦掉，请对比原图，不合适的字保持不选。置信度不是正确率保证。字体、字号、位置近似；公式、手写字、旋转字、极小字尚不能保证准确。review JSON v2 明确标记为未验证观察；修改可能是纠错，也可能是主动改名，不能直接当成训练真值。目前未训练或部署 XGBoost。

工程与科研共用的验收标准、对照实验及停止条件见 [开发契约](development-contract.md)。运行 `npm run diagnose:ocr` 可复现九个小型擦字诊断用例：分别报告是否替换、旧字移除、图形损伤及错字，保留已知失败。这里直接提供文字及位置，只隔离测试擦字步骤，不是 OCR 精度测试或正式论文结果。

每个可处理的文字框旁新增 **Review mask**：左侧用粉色显示将擦除的字迹，绿色表示保护范围；右侧预览擦字后、添加新文字前的图形。可保护线条、取消保护、撤销或重置，点击 **Confirm mask & replace** 才保存，直接关闭不会保存草稿。**Suggest protection** 用连通区域规则建议保留延伸到文字框外的前景及细长线条，不需要新模型。文字和线条粘连时可能一起留下，框内短小图形也可能漏掉，必须检查并调整；不能当成自动分割已解决。确认掩码可解锁被横/竖线保护规则暂停的文字，但复杂背景仍不允许擦除。范围上限为 262,144 像素、64 笔、2,048 个点。导出的 review JSON 保存操作，但仍不是已验证的训练标注。

诊断还包含连通区域建议（模拟确认，并非用户实验）和已知像素归属的参考对照。斜线粘连例中，建议仅移除约 22.4% 的旧字像素；正确像素归属能完成该例的擦字，但修不好文字识别本身的错误。这是定位瓶颈的机制检查，不是通用准确率或顶会级成果。

单个拉丁字母/数字及带括号的短标识符，即使置信度很高，也不默认选中，请看原图后明确纠正或选中。真实主图检查中出现过 `(B)` 被高置信度读成 `(8)`；这条规则降低自动覆盖率来避免默认替换，并没有自动修好 OCR，也不能覆盖所有公式错误。

已有文字框旁的 **Re-read label** 可单独重读，比较三种布局候选。选择候选只更新文字草稿，不自动选中替换，也不改原框或图形；缺失的文字框不能靠它找回。置信度和多次结果一致都不保证正确，公式仍需手动核对。它仅是完整 SVG 生成流程的辅助检查，不是另做一个 OCR 产品。

图片工作区输入上限 20 MB、24 百万像素。本地描摹最长边缩到 768 像素，适合平面示意图、图标；复杂照片、细小文字和公式可能失真。动画输入只导出浏览器解码的一帧。

## PDF 与 PowerPoint 文档工作区

网页下半部分的 PDF & slides 提供 13 个真实工具入口：PDF 转文字可编辑 PPTX、页面图片 PPTX、PNG/JPEG/WebP 页图 ZIP、TXT；合并、选页/重排/重复、拆分、旋转 PDF；批量图片转 PDF/PPTX；单页送进图片工作区；PPTX 提取文字和内嵌图片。

输入队列可调整顺序、移除和清空。全部页留空或填 `All`，指定页例如 `3,1,2-4`。上限 25 文件、50 MB、200 页；渲染每次最多 40 页、32 百万像素。PPTX 解包上限 100 MB、1,000 文件。

PDF 转文字可编辑 PPTX 依赖文字层：原有字形从背景移除，文字变成原生文本框；图形仍是图片，字体/颜色/位置近似。扫描件可通过 PDF page → figure studio 将单页送入 OCR 工作区，暂不支持整本扫描 PDF 批量识字。PPTX 提取图片不是幻灯片渲染。图片转 PDF/PPTX 使用白底，最长边超过 4,096 会缩小。

这些工具本地运行，不自动上传。带表单/签名字段的 PDF 拒绝重排。尚未提供 Office/PPTX 转 PDF、Word/Excel、压缩、加密文件、EPS、旧版 `.ppt` 或局部语义重建；不声称是超过 Smallpdf 的万能转换器。

## AI 接口与隐私

设置按钮中填入支持视觉输入的 chat-completions 兼容接口、模型 ID 和密钥。勾选明确同意后，点击 Rebuild 才会发出请求。密钥仅存在当前页面的输入框中，不持久保存；只发送到你指定的地址。接口需支持浏览器 CORS 请求。服务商可能收费和保留图片，在投稿件请先确认允许外发。

没有接口也可以使用 Copy prompt，把图片及提示词发给自己的 AI，再点 Import JSON 导入回复。完整说明见 [ai-rebuild.md](ai-rebuild.md)。
